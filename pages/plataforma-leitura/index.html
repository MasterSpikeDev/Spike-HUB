Como usar esta versão

Agora este HTML usa PDF.js e renderiza uma página por vez no centro. Isso significa que o próprio site controla a página atual, então o fundo e a música mudam automaticamente.

Você só precisa colocar os arquivos certos nos caminhos configurados em CONFIG.

1) PDFs Ajuste CONFIG.pdf.desktop e CONFIG.pdf.mobile com os nomes dos seus arquivos.
2) Fundos Em cada item de CONFIG.scenes, ajuste background para a imagem daquela cena.
3) Músicas Em cada item de CONFIG.scenes, ajuste audio para a trilha ou ambiente em loop daquela cena.
4) PDF.js Este HTML já puxa o PDF.js por CDN. Para publicar online, basta manter internet na página ou depois trocar para arquivos locais do pdf.js.
Estrutura sugerida: index.html, PDFs, assets/bg e assets/audio dentro do mesmo projeto.
